# Division II 购物车与比赛物品选型 v2.0

> 状态：设计采购候选；未购买、未到货、未实测。当前唯一购物车基线为中国大陆采购的60L金属网篮超市购物车。尺寸和质量均为目标值，不是验收数据。

## 1. 购物车唯一候选

**60L紧凑型金属网篮超市购物车，1台。**

- 采购渠道优先淘宝/天猫中国大陆卖家；商品链接暂不填，等待按规格筛选具体SKU。
- 目标外廓参考：长约750–780mm、宽约450–460mm、高约880–960mm；不同厂家差异较大，不能只按“60L”容量下单。
- 结构目标：钢丝网篮、钢管/金属底架、推把、四个脚轮；优先可提供尺寸图、空车重量、框架管径和脚轮安装尺寸的卖家。
- 选型理由：符合标准超市购物车外观，金属底架便于重新设计可拆牵引接口；相较布篮折叠wagon，更容易确认刚性受力路径。
- 风险：卖家标称承载不等于拖挂/冲击/转弯能力；牵引连接须经过结构审查和防脱测试。

**已撤销：** Sakugi 80L布篮折叠wagon不再是本项目购物车候选，不采购。旧文件中的布篮硬底板/布带受力方案全部作废。

到货后记录：具体SKU、订单/收据、外廓、篮口内尺寸、篮底尺寸、框架管径/截面、空车质量、脚轮直径/安装孔距、把手高度。先做可逆夹具样件，不先切割/焊接购物车。牵引点只能落在金属承载框架，不得夹薄钢丝网格。

最终实际购买/交付的三件物品：PET瓶、泡沫球、红色替代盒。蓝色缺货货位牌是团队制作的演出标识，不是第四件购买物品。

## 3. 操作接口

- PET瓶：圆柱形，中段夹持；保持空瓶、带盖、无尖角。
- 泡沫球：使用软垫夹爪或浅托杯承托，不用尖齿夹紧。
- 红色小盒：平底平行侧面，适合平行夹爪和独立卸载托盘。
- 三件物品均避免玻璃、液体、尖锐边缘和易碎电池。
- Division II独立卸载装置必须与车辆分离；不允许车载机械臂/翻斗替代。
