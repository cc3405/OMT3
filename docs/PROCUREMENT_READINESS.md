# 采购准备与设计冻结台账

> 版本：PROCUREMENT-READINESS-1.0（2026-10-30）
>
> **用途：** 把现有 BOM 转成可执行的分阶段采购门禁。本文不代表已完成工程设计，也不是购物车、座椅、车架、转向或制动件的认证选型。
>
> **当前采购结论：** 只允许采购通用工具、低风险样品和与载人安全无关且尺寸已确认的物品。不得按旧机器人 BOM 直接购买/制造载人承载结构、驱动、转向、制动、电池或电气保护系统。

## 1. 采购状态定义

| 状态 | 含义 | 下单条件 |
|---|---|---|
| A — 可先买 | 通用工具、测量用品、低风险训练耗材；即使方案调整也可继续使用 | 核对现有库存，避免重复采购；记录实际价格和凭证 |
| B — 尺寸/样品确认后买 | 标准购物车、非承载支架样品、道具和卸载装置材料 | 先取得实物尺寸/卖家图纸；确认与场地、结账区、外廓和团队方案兼容；优先可退换 |
| C — 工程冻结后买 | 主车架、座椅及安装、轮组、车轴、轴承、转向、制动、驱动总成、电池/BMS、接触器、保险丝和主线束 | 完成 CAD、载荷/重心/稳定性/制动/电气计算，专业审查，数据表核验和预算审查 |
| X — 禁止沿旧清单购买 | 与载人目标冲突或未经验证的旧机器人规格 | 先完成重新设计；不得把旧型号自动迁移为载人车辆部件 |

| 项目 | 采购策略 | 下单前必须拿到 | 到货验收 |

| 独立卸载装置材料 | 先做纸板/木条低成本样机，再按实测道具尺寸买板材/铰链/手柄 | 三件道具最大外廓和质量、结账区域尺寸、装置占地和人手操作路径 | 三件物品连续卸载，装置与车辆完全分离，操作员不需危险夹持 |
| 非承载防护样件 | 只买小样验证包边/护罩工艺 | CAD 外形、运动件扫掠区、材料阻燃/耐冲击要求（如适用） | 无锐边、无夹点新增风险、不干涉转向/车轮 |
| 电子开发样件 | 仅用于桌面逻辑/传感器实验 | 准确开发板 SKU、引脚图、固件接口 | 单独限流台架验证；不得连接载人安全回路 |
| 低风险连接器/线束样件 | 只买少量样品 | 接头系列、线径、端子额定值、环境要求 | 压接拉力/导通/极性检查；样件通过后再批量采购 |

### C — 工程冻结后买（不得提前定型号/数量）

| 系统 | 冻结所需文件/数据 | 未完成前禁止事项 |
|---|---|---|
| 主承载车架/座椅/脚踏 | 完整 CAD、载荷路径、材料/截面/连接计算、疲劳与动态工况、重心与倾覆分析、专业审查 | 不买定制板材/型材，不钻孔焊接，不让人坐上去 |
| 车轴/轮毂/轴承/轮胎 | 各支点轮荷、偏载/侧向/冲击工况、轴承寿命、轮胎抓地和速度等级核验 | 不按“单轮额定值×轮数”选型 |
| 转向系统 | 转向几何、转弯半径、机械限位、连接强度、故障状态和防松设计 | 不用现有差速驱动替代已验证机械转向 |
| 行车制动/驻车制动 | 目标总质量/速度/坡度/附着条件、制动能量、制动距离和保持能力设计 | 不把电机反接、软件 PWM=0 或急停断电当作行车制动 |
| 电机/减速箱/驱动器 | 整车质量、轮径、坡度、加速、连续工况、热平衡；具体 SKU 额定/堵转电流与扭矩数据 | 不沿用 JGB37-520 / BTS7960 作为已批准载人驱动组合 |
| 电池/BMS/接触器/保险丝/线束 | 最坏工况电流、分支保护、线径/长度/温升、DC 分断能力、充电与固定方案 | 不先买 3S 5000mAh 或按宣传峰值电流定保护件 |
| 速度/控制安全 | 独立限速、失电/故障安全状态、急停回路、驱动禁用逻辑及验证计划 | 不将 ESP32 普通应用固件作为唯一安全保护层 |

| 65–80 mm 驱动轮 + 后万向轮 | 从载人底盘候选中移除 | 现有两驱差速+后脚轮布局未证明乘坐者重心下的稳定性、转向和制动能力 |
| 300×250×6 mm 底盘毛坯 | 禁止作为载人主承载板直接加工 | 未形成座椅至轮组的合格载荷路径，尺寸也未冻结 |

| 3S 电池、BMS、保险丝、主接触器 | 等待系统电气计算 | 需要真实电流、热负荷、分支保护和 DC 分断能力 |
| 车载商品机械臂舵机/PCA9685/夹爪 | X — 本轮取消 | 用户已同意取消；独立卸载装置仍需单独满足适用组别题目要求 |

| 独立人力卸载装置 | B — 先做低成本样机 | 装置必须与车辆完全分离；先按实际道具尺寸制作纸板/木制验证模型 |

## 4. 预算台账（禁止填估算冒充实价）

每笔采购单独记录，金额以实际订单/收据为准。赛事成本按当季 Program Guide 和 Problem 限制的正式口径计算，不因本表使用人民币就自动合规。

| 编号 | 品名/具体 SKU | 数量 | 单价 | 运费/税费 | 实付币种 | 折算 USD | 汇率与日期 | 是否计入赛事成本 | 凭证链接/照片 |
|---|---|---:|---:|---:|---|---:|---|---|---|
| P-001 | 待填 |  |  |  |  |  |  | 待核对 |  |
| P-002 | 待填 |  |  |  |  |  |  | 待核对 |  |
| P-003 | 待填 |  |  |  |  |  |  | 待核对 |  |

预算公式：

- 订单实付 = 商品金额 + 运费 + 税费 − 实际折扣/退款。
- 折算 USD = 订单实付 ÷ 采购当日记录的 USD 汇率（如按官方成本规则要求其他汇率，按规则替换）。
- 剩余预算 = US$165 − 已确认计入赛事成本的折算金额。
- 任何成本豁免必须附 Program Guide 对应条款；没有依据时按需计入处理，不自行假设豁免。

## 5. 采购前设计冻结清单

- [ ] 队伍组别已确认；明确独立卸载装置是否适用于该组别，并按完整题面/Program Guide 核验。
- [ ] 乘客体重下限 35 kg、额定乘客承重至少 40 kg；最大乘客质量另由工程设计确定。
- [ ] 首版速度目标上限 10 km/h；比赛试验从步行速度起步，20 km/h 仅作未来独立评估。
- [ ] 车辆外廓、标准门洞通过性、车宽≤800 mm 和全行程扫掠包络已在 CAD 中标注。
- [ ] 乘客、座椅、电池、购物车连接件和货物的总质量及重心已计算/实测。
- [ ] 车架、座椅固定、轮组、转向、行车制动、驻车制动和防护已完成专业审查。
- [ ] 购物车具体 SKU 尺寸已取得并实测；牵引连接与释放机构完成 CAD。
- [ ] 电机/驱动器/电池/BMS/接触器/保险丝/线径已完成电气与热设计。
- [ ] 预算按实际凭证核算，符合赛事 US$165 成本限制；若安全件超预算，暂停并重做可行性，不削减安全件。
- [ ] 采购清单由机械、电气、规则/成本负责人共同复核并签字。

## 6. 规则更新：2026–2027 官方一般澄清

官方 Problem 1 澄清页面当前列出：

- **2026-09-15：** Figure A 中 Start Line 距购物车区和结账区顶部 6 ft，并位于两者之间的居中位置；Shopping Area 是图中 Start Line 以下、除 Checkout Zone 和 Cart Area 以外的全部区域，标示 6 ft/10 ft 的虚线仅用于标尺寸，不是购物区边界。

3. 比赛前再次检查官方澄清页面，后续更新优先于旧版题面摘要。

## 7. 本轮结论

- **现在可以开始：** 盘点工具、采购测量工具（缺什么买什么）、询价 60L 购物车、制作独立卸载装置低成本样机、采购少量非安全关键电子样件。
- **现在不可以：** 按旧 BOM 一次性买齐载人底盘；定制车架/座椅/轴/转向/制动；按旧电机型号定电池/BMS/保险丝；真人试坐。
- **采购冻结状态：** 未冻结。只有第 5 节清单完成，且工程/规则/预算负责人审查通过后，才发布带具体 SKU、数量、单价和加工图的最终采购 BOM。
