# OMT3 参数化3D概念模型 v1

## 文件
- `cad/omt3_concept_v1.scad`：OpenSCAD参数化源文件，可继续修改。
- `cad/omt3_concept_v1.stl`：本地导出的装配网格（需重新导出/上传到仓库后才可作为仓库文件使用）。
- `omt3_concept_v1.png`：概念渲染图（随交付附件提供）。

## 构型
- 四轮低速车辆底盘、座椅/操纵杆外形占位（不代表载人安全批准）。
- 车辆前部固定式三执行器机械臂：肩、肘、夹爪；软质V形夹爪的开口目标至少90mm。
- 前、左前、右前三个超声波传感器占位。
- 后部万向牵引杆与独立购物篮拖车。
- 另有一台空间分离的独立落地手动滑动托盘卸货器；不得与车辆或购物车连接。

## 与参考图的差异
参考图的机械臂似乎装在拖挂篮/篮架附近，可能随拖车摆动，不能作为稳定抓取基准。本模型把机械臂固定在车辆底盘前端；车辆停车并禁用驱动后抓取，再将物品放入拖挂篮。卸货仍由完全独立的手动卸货器完成。

## 重要限制
- 这是布局概念模型，不是可直接加工的制造图、认证车辆CAD或结构安全证明。
- 所有外廓、连接件、轴距、轮距、臂长、舵机、牵引件和卸货器尺寸均须按实物测量、计算与测试更新。
- 座椅/操纵杆仅为外观布局占位。未完成专业结构、稳定性、转向、制动及乘员安全审查前，不得真人乘坐或动力载人测试。
- 牵引连接须做满载质量、弯折角、转弯半径、防脱和疲劳校核；未审查前不得拖行测试。
- 超声波不能识别物品类别；本模型不含视觉定位。抓取需固定取物点/姿态。
- 独立卸货器必须独立落地、手动操作，与车辆机械、电气、控制完全分离。
- OpenSCAD CGAL网格检查通过（单个STL包含多个分离实体）；这不等于物理可装配或结构验证通过。
