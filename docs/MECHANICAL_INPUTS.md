## 3. 质量与载荷工况

分别记录车辆自重、乘员质量、购物车自重、购物物品、电池和附件质量，计算总质量与各轮静态轮荷。不得用“40 kg除以4轮”代替轮荷分析。

- 静态额定载荷：乘员质量范围、座椅/脚踏/约束载荷路径、偏坐。
- 偏载与上下车：重心偏移、单侧轮荷和瞬态载荷。
- 制动：设计速度、总质量、减速度、轴荷转移和轮胎附着。
- 转弯：速度、转弯半径、重心高度、轮距和侧向载荷。
- 路面冲击：接缝、局部障碍、轮胎冲击和疲劳。
- 购物车拖挂/释放：购物车及物品质量、挂点高度、牵引角和释放瞬态；首轮不拖挂满载购物车进行载人动态测试。

载荷组合、材料截面、连接方式、焊缝、紧固件等级、允许应力及安全系数必须由合格工程人员依据适用规范确定；本文件不预设安全系数。

## 4. 子系统设计输入

- 车架必须从座椅、脚踏和乘员约束点形成连续载荷路径；薄底板、外壳、单根2020型材或单个角码不得未经计算认定为主承载结构。
- 轮组、车轴、轴承和紧固件按实际轮荷、冲击、侧向力、轴弯曲和连接方式选型，不能只用单轮标称载荷乘轮数。
- 转向需有机械限位、无卡滞和失效分析，不能依赖软件单点维持方向。
- 行车制动必须具备可验证能力；驻车制动须机械保持，断电不得溜车。
- 硬件急停进入驱动安全状态；不能只依赖ESP32普通应用固件发停止命令。
- 电池、BMS、接触器、保险丝、线束和连接器按持续/峰值/堵转及故障电流协调设计；旧3S电池不得默认沿用。
- 购物车连接、锁止和释放需有误释放防护；拖挂工况与载人本体分开验证。

## 6. 采购冻结

在CAD外廓、总质量与轮荷、重心、结构载荷工况、转向/制动架构和电气负载完成审查前，不得采购或加工最终车架、座椅固定件、车轴、轮组、转向节、制动器、电机/减速器、电池/BMS、接触器、保险丝及主线束。仅可先采购通用测量工具和低风险样件；采购记录见 docs/PROCUREMENT_READINESS.md。

## 7. 载人放行门槛（全部满足前禁止真人乘坐）

- [ ] 设计质量范围、总质量、轮荷和重心已测/算并经专业人员签核。
- [ ] 车架、座椅、脚踏、约束、轮组、转向、行车/驻车制动及紧固件审查通过。
- [ ] 无人静态及固定配重静态验证通过，记录无永久变形、松脱或异常。
- [ ] 无人离地驱动、转向、制动、驻车制动和硬件急停测试通过。
- [ ] 封闭隔离场地内按步行速度逐级配重动态验证通过，记录转弯、制动距离和失效行为。
- [ ] 购物车拖挂/释放单独验证；不与首轮载人动态测试混做。
- [ ] 适用法规、场地许可、监护和应急方案确认。
- [ ] 合格工程人员书面放行。

**没有满足全部门槛时，项目状态必须写为“载人功能未放行/禁止真人试乘”。**
