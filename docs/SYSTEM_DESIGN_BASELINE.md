# OMER载人购物车系统设计基线（理论方案版）

> 状态：概念设计基线 / 理论可行性论证。用于2026-10-31 08:00阶段验收，定义总体方案、接口、计算方法和设计冻结条件；不是施工图、认证设计或真人乘坐许可。

## 1. 设计结论摘要

建议采用**四轮低重心电动载人平台 + 前轮机械转向 + 后轴差速驱动 + 独立行车/驻车制动 + 可拆卸购物车 + Division II独立卸载装置**的总体架构。

- 乘员体重下限35 kg；额定乘员承载至少40 kg。40 kg是最低额定承载需求，不是乘员最大体重；最大设计乘员质量须另行确定。
- 首版设计速度目标最高10 km/h；比赛验证从步行速度起步。20 km/h不纳入首版设计。
- Program Guide一般规则要求解题方案及运输容器通过28 in × 78 in（约711 × 1981 mm）门洞；整车、购物车及所有需运输部件均须按最大外廓验证。
- 车载抓取机械臂取消。购物车内物品按任务流程装载；**Division II必须使用队伍制作、且与车辆分离的卸载装置**。
- 旧差速机器人底盘、电机/驱动板组合及薄底板均不作为载人底盘直接沿用。
- **理论可行性判断：**机械与控制架构在概念层面可实现，但总质量、几何、轮荷、结构、制动和电气参数化计算尚未闭环。US$165预算约束是高风险条件，必须单独核算。

### 2.2 理论分析假设

- 初始工况按平整、干燥、室内硬质地面考虑；湿滑地面、坡道、门槛和户外路面不作首版性能承诺。
- 采用四轮支撑，前轮机械转向，后轮由电驱动总成推进。
- 购物车仅在车辆本体完成独立审查后进行连接/拖挂评估；首轮不把满载拖挂纳入载人动态工况。
- 不预设车辆空载质量、乘员最大质量、货物质量、轮距、轴距、重心高度、轮胎半径、坡度、制动减速度或电机功率。

### 2.3 规则边界

- 乘员在车辆移动时完全由车辆支撑，不得触地；车辆须自成一体，不依赖外部动力。
- 车辆原创性、推进方式、购物车连接/释放和8分钟任务流程按完整题面核对。
- 2026-10-01澄清：购物清单在计时开始时交给操作员，且必须早于车辆越过Start Line。
- 2026-09-15澄清：Figure A区域按官方定义放样；6 ft/10 ft虚线仅标尺寸，不是购物区边界。
- **Division II属于官方要求独立卸载装置的Division 2–4范围。必须使用队伍制作的卸载装置；装置须与载人车辆分离，不能把车载机械臂、舵机翻斗或车体一体式机构当作该独立装置。**
- 购物车结账后须按题面完成释放、独立行进并停在购物车区域；仅机械脱钩不代表任务完成。
- US$165成本范围和豁免按当季Program Guide核对，不自行假设豁免。

## 3. 总体系统架构

| 层级 | 模块 | 功能 | 设计边界 |
|---|---|---|---|
| 乘员层 | 座椅、靠背、脚踏、扶手/防护 | 支撑乘员、保持姿态、保护脚部 | 连接主承载结构；最大乘员质量待定 |
| 结构层 | 主车架、横梁、安装节点、护罩 | 传递乘员、动力、制动和牵引载荷 | 连续载荷路径；截面与连接由计算确定 |
| 行走层 | 四轮、前转向节、转向拉杆、后驱动桥 | 支撑、转向和推进 | 前轮机械转向；后轴差速驱动 |
| 制动层 | 行车制动、驻车制动、急停 | 减速、保持、故障停止 | 机械制动独立于任务软件 |
| 能源层 | 电池、BMS、主保险、接触器、线束 | 提供并保护电能 | 按连续/峰值电流、热和故障分断设计 |
| 控制层 | 任务控制器、驱动接口、传感器 | 任务状态机和低速运动命令 | ESP32-S3仅任务逻辑候选，不作唯一安全控制器 |
| 任务层 | 订单、库存、替代决策、结账、释放 | 管理赛题流程 | 清单交接是越线前硬门槛 |
| 外部任务件 | 可拆卸购物车、独立卸载装置 | 购物、装卸、返区 | 购物车可释放；Division II卸载装置必须独立于车辆 |

### 3.1 机械布局概念

- 前部：左右前轮、转向节、横拉杆、方向把手/转向柱、机械转向限位。
- 中部：低位座椅、脚踏区、主承载横梁；乘员尽量布置在轴距范围内。
- 下部/中后部：低位固定电池、后驱动桥/减速机构、行车制动和驻车机构。
- 后部：购物车牵引接口，连接载荷传入主车架加强节点，不连接薄外壳。
- 运动部件：链条、齿轮、转向连杆和轮胎夹点设置护罩；乘员脚部与车轮/传动件隔离。
- 购物车：独立承载货物，连接器兼顾转弯扫掠、牵引力、侧向力和快速释放。

### 3.2 载荷路径

乘员/座椅 → 座椅支座 → 主纵梁/横梁 → 前后轮安装节点/车轴 → 轮胎接地面。

驱动反力：电机/减速器 → 驱动桥安装座 → 主车架。

制动反力：制动器安装点 → 车轴/转向节/车架节点；不得通过装饰板或未经验证的薄板传递。

牵引载荷：购物车连接头 → 加强安装节点 → 主车架纵向结构；校核拉力、侧向力、偏载和脱开瞬态。

## 4. 关键子系统设计

### 4.1 主车架与座椅

概念采用左右主纵向承载构件与前后横向连接构件形成抗扭框架；座椅支座落在主承载节点附近。材料可比较结构钢与铝合金，依据截面惯性矩、屈服/疲劳性能、可加工性、连接工艺、质量和成本确定。

设计必须完成：
1. 主梁弯曲、剪切、扭转和局部屈曲计算；
2. 座椅、转向、驱动桥、制动和牵引安装点的局部承压/撕裂/螺栓剪切校核；
3. 焊缝、螺栓、销轴和防松结构校核；
4. 静载、偏载、制动、转弯、冲击及疲劳工况校核；
5. 座椅、靠背、脚踏和扶手连接及防夹/防滑设计。

不预设板厚、型材规格、螺栓等级或焊缝尺寸。不得把300×250×6 mm旧底板、2020型材或单个角码直接作为主承载结构。

### 4.2 四轮支撑与前轮机械转向

采用四轮布局形成稳定支撑多边形。前轮通过转向节和横拉杆联动，方向把手/转向柱输入转角，设置机械限位和防松。转向几何应尽量接近Ackermann几何，使内外前轮在转弯时具有不同转角。

理想低速转弯关系：轴距L、前轮转角δ时，转弯半径近似 R = L / tan(δ)。轮距T、内外轮转角及车轮扫掠包络由CAD运动学校核。最大转角由轮胎/车架干涉、购物车扫掠和稳定性共同限制。

必须分析转向柱失效、拉杆脱落、球头松脱、机械限位失效和满载拖挂时的响应。软件左右轮差速不替代机械转向。

### 4.3 后轴驱动

概念采用后轴差速驱动：经选型的电机/减速器驱动差速器，再由左右半轴驱动后轮。差速器允许转弯时左右后轮具有不同转速，降低轮胎拖曳。电机、减速器、差速器、半轴和安装结构由团队设计集成，体现原创推进方案；商业电机/轴承可作为部件，仍须核对官方原创性和成本条款。

驱动选型需校核轮端牵引力、坡度、加速、持续运行热负荷和减速器输出扭矩，不能只看空载转速或标称峰值功率。

### 4.4 行车制动、驻车制动与急停

- 行车制动：独立机械或液压制动系统，作用于经计算选定的车轮/车轴。
- 驻车制动：具备机械保持能力；上下车和停放时不依赖电机保持力。
- 急停：乘员和安全观察员可触及；硬件安全回路撤销驱动使能/打开主接触器；触发后需手动复位，复位不得自动恢复驱动。
- 低电量、控制器掉电、通信丢失和驱动器故障时，仍须保留机械制动能力。

基本关系：10 km/h = 2.78 m/s；动能 E = 0.5 × M × v²；理想恒减速度制动距离 d = v² / (2a)。实际停车距离还要计入响应延迟、坡度、轮胎附着、载荷转移和制动衰退。相同质量下20 km/h动能是10 km/h的4倍，因此首版不采用20 km/h。

**仅按40 kg额定乘员载荷计算的下限示例：** 静态重力载荷约为40 × 9.81 = 392 N；10 km/h时乘员载荷本身对应的平动动能约154 J；20 km/h时约617 J。真实整车还包含车架、电池、座椅、驱动系统及可能的货物/拖挂质量，因此真实制动能量必然高于仅计算40 kg乘员的示例值。该示例只说明速度平方关系，不是结构或制动器选型结果。

### 4.5 电源与电气保护

建议拓扑：电池包 → 主保险 → 主接触器 → 驱动器/电机支路；另设独立受保护的低压逻辑支路 → 任务控制器/传感器。BMS负责电池包保护，但不能替代各支路保险和线束保护。

设计输入包括电池体系、串并联数、连续/峰值电流、短路电流、接触器DC分断能力、保险丝时间-电流曲线、线束长度/敷设/温升、连接器额定值、充电方式和电池固定。参数须按最终驱动总成数据表计算后冻结。

ESP32-S3只负责订单、状态机、低速命令和非安全关键传感器；驱动使能、急停、过流/过温和失效停止由独立硬件/驱动安全链路实现。软件PWM归零不是机械制动。

### 4.6 购物车连接与释放

购物车独立支撑货物，车辆通过机械牵引接口带动。连接点位于主车架加强节点，设置主锁止件、二次防脱和可视状态标记。连接器允许必要偏航/俯仰自由度，角度由CAD扫掠分析确定。

释放后购物车须依题面自行行进并停入Cart Area。若需弹性/储能推进，应独立评估能量、方向稳定、碰撞风险和赛道边界。释放失败时不得让车辆继续拖行购物车进入危险姿态。

### 4.7 Division II独立卸载装置（强制纳入）

官方Problem 1页面将Division 2–4列为必须由队伍制作卸载装置的组别；本队按Division II设计，故此项不是可选项。

**边界要求：**
- 卸载装置必须由队伍制作，并与载人车辆分离；不得安装在车辆上或依赖车体作为装置主体。
- 已取消车载抓取机械臂，不得以车载舵机、翻斗或车体一体式机构替代独立卸载装置。
- 独立装置的操作、放置位置、卸载对象数量/顺序和计分条件，最终以完整Problem 1题面为准。

**概念方案：**采用独立桌面式重力导向滑槽/翻板托盘。队员将购物物品逐件放入承托位，通过手柄或翻板将物品送入结账区。结构与车辆没有机械连接，也不从车辆取电。按题面物品尺寸/质量、结账区高度、操作员可达范围、防滚落、防夹手和8分钟任务时间确定几何参数。

**理论验证项目：**物品逐件通过率、卡滞概率、滑落/弹出风险、操作力、放置稳定性、与结账区边界的兼容性、操作时间。先做纸板/低成本独立样机；不需要把该装置改成车载机构。

## 5. 参数化工程计算框架

总质量 M = 车辆空载质量 + 乘员质量 + 车辆承载货物质量。购物车由车辆牵引时，另建拖挂载荷模型，不把拖挂质量错误地全部计入车辆静态轴荷，也不能漏算牵引载荷。

### 5.1 轮荷与支撑

静态平地总法向载荷近似 W = M g。四轮轮荷不能简单假定各占25%；须依据重心纵横向位置和支撑点坐标计算。制动、加速、转弯和地面不平会改变动态轮荷。

### 5.2 结构载荷工况

至少定义：
- LC1：额定乘员载荷静态居中；
- LC2：乘员偏左/偏右、前倾/后仰偏载；
- LC3：制动时纵向载荷转移及座椅/靠背载荷；
- LC4：转弯时横向载荷转移；
- LC5：车轮遇接缝/小障碍冲击；
- LC6：购物车牵引、转弯侧向力和释放瞬态；
- LC7：重复运行疲劳载荷。

载荷系数、安全系数和材料许用值由工程人员依据材料数据、制造工艺和适用标准确定；本方案不编造统一系数。

### 5.3 驱动功率估算

平地滚动阻力 F_rr = C_rr × M × g；坡度阻力 F_grade = M × g × sin(θ)；加速需求 F_acc = M × a。轮端牵引力 F_t = F_rr + F_grade + F_acc（另计风阻、拖挂阻力和传动损失）。轮端功率 P_wheel = F_t × v；电机输入功率 P_elec = P_wheel / η，其中η为传动总效率。

选型须校核连续功率、峰值功率、低速扭矩、起步电流、减速器热容量和工作周期。坡度、滚阻、总质量和加速度未知时，不给出可信的电机瓦数。

### 5.4 制动计算

以总质量M和设计速度v计算动能 E_k = 0.5 M v²。目标平均减速度a_b由制动距离和稳定性要求确定，理论制动距离 d = v²/(2a_b)。制动器需校核吸收能量、热衰退、轮胎附着限制、前后制动力分配和驻车保持力。再生制动不能作为唯一制动方式。

### 5.5 稳定性

通过CAD求整车（含乘员）重心位置和高度，建立四轮接地点支撑多边形。静态重心投影须位于支撑多边形内并留工程余量；动态转弯考虑横向加速度 a_y = v²/R、重心高度、轮距、轮胎侧向力和路面横坡。转弯速度上限由稳定性分析和试验共同确定，不能仅以软件限速代替。

### 5.6 质量预算

逐项记录车架、座椅、转向、驱动桥、电机/减速器、电池、制动、线束、护罩、控制器、购物车接口和附件质量。分别记录空车、乘员、货物、购物车自重和拖挂质量，避免漏算或重复计入轴荷。

## 6. 控制系统与任务状态机

### 6.1 控制分区

- 任务控制器：订单输入、库存状态、替代选择、任务时序、日志和非安全关键显示。
- 运动控制接口：接收低速前进/转向目标并输出驱动请求，不承担唯一制动保护。
- 硬件安全链：急停、驱动使能、主接触器和故障锁止；优先级高于任务状态。
- 人工操作：乘员/操作员控制转向和行驶许可；任务自动化不得在无人确认时突然驱动车辆。

### 6.2 任务状态机

| 状态 | 进入条件 | 动作 | 离开条件/保护 |
|---|---|---|---|
| SAFE_IDLE | 上电/复位 | 驱动禁用、制动保持 | 自检通过且人工复位 |
| PRESTART_CHECK | 开始前 | 检查电池、急停、制动、购物车连接和场地 | 任一失败保持禁用 |
| ORDER_LIST_HANDOFF | 计时开始 | 购物助理交付清单 | 操作员确认持单 |
| VERIFY_OPERATOR_HAS_LIST | 已交单 | 记录确认 | 未确认不得越线 |
| CROSS_START_LINE | 清单已确认且场地许可 | 低速越线 | 记录越线事件 |
| SHOPPING | 操作员控制车辆 | 进入购物区并收集商品 | 购物任务完成 |
| SUBSTITUTE_APPROVAL | 商品缺货 | 购物助理提出并批准替代 | 替代品确认后继续 |
| CHECKOUT | 到达结账区 | 核验三件物品和订单 | 核验通过 |
| UNLOAD | Division II任务阶段 | 使用与车辆分离的队伍自制卸载装置 | 物品按题面进入结账区并确认 |
| CART_RELEASE | 达到题面释放条件 | 执行购物车释放 | 确认连接状态分离 |
| CART_RETURN | 购物车独立移动 | 观察其进入Cart Area并停稳 | 区域与静止条件满足 |
| VEHICLE_PARK | 车辆停止 | 驻车制动、驱动禁用 | 安全结束 |
| DONE | 所有任务条件完成 | 保存日志 | 结束 |
| FAULT_STOP | 任一安全/控制故障 | 驱动禁用、制动、报警 | 排故并人工复位 |

任何状态下急停触发均进入FAULT_STOP。复位不得自动继续上一个运动动作。清单交接确认必须发生在CROSS_START_LINE之前。

### 6.3 故障处理

| 故障 | 预期反应 |
|---|---|
| 急停按下 | 硬件撤销驱动使能，机械制动按设计进入安全状态，需人工复位 |
| 控制器复位/掉电 | 不得产生驱动脉冲；驱动默认禁用 |
| 通信超时/传感器异常 | 停止新运动命令，保持/施加制动并记录 |
| 电池欠压/过流/过温 | BMS/硬件保护动作，驱动禁用 |
| 转向反馈异常/机械卡滞 | 停止驱动，进入人工检查 |
| 购物车连接状态未知 | 禁止释放/继续拖行 |
| 清单未交接 | 不允许越过Start Line |

## 9. 理论可行性结论

从功能分解看，四轮机械转向载人平台、后轴差速驱动、独立机械制动、硬件急停、可拆卸购物车和Division II独立卸载装置不存在明显原理冲突，可以形成完整概念设计。但能否满足实际40 kg额定乘员承载、10 km/h目标、稳定性、门洞、8分钟流程和US$165成本，仍取决于真实质量/几何/材料/部件数据及计算结果。
