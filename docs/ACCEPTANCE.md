## 测试证据模板

- 日期/场地、操作员、观察员
- 硬件型号、固件 commit、Arduino-ESP32 与 ESP32Servo 版本、接线和电池状态
- 场地尺寸、负载、测试步骤和预期结果
- 实际结果、通过/失败、异常复现方式
- 修复 commit、回归结果、视频/照片/采购凭证

源码检查和 Python 单元测试不能证明 Arduino 编译、传感器、机械机构或完整比赛流程通过。实机验收必须在真实设备上完成。
