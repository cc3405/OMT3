# Division II 独立卸载装置 — 概念基线 v0.1

> 状态：概念方案，未冻结尺寸、未制作、未实测。  
> 适用基线：团队已确认 Division II。正式报名/教练确认及最新官方规则复核仍须归档。  
> 安全边界：本装置与乘坐式车辆完全分离；不连接车辆，不使用车辆供电，不把车载机械臂/翻斗作为本题卸载装置。

## 1. 规则与设计目标

官方 Problem 1 页面说明：Division II、III、IV 的物品须由队伍制作的装置卸载。Division II 因此必须把队伍自制卸载装置纳入解题方案，而不是可选附件。

官方来源：
- Problem 1 – OMER’s Shopping Service: https://odysseyofthemind.com/problem-1/
- General Clarifications: https://odysseyofthemind.com/read-clarifications/
- 2026–2027 Program Guide: https://odysseyofthemind.com/program-guide/

设计目标：
1. 从购物车中取出三件比赛物品，并将其放入结账区域。
2. 装置独立落地，与车辆没有机械、电气或控制连接。
3. 由队员按题面允许方式操作；不为追求自动化而增加电机、舵机或复杂控制。
4. 保护易碎/不规则物品，避免滑落、夹手、倾覆和碰撞。
5. 快速布置、容易复位，能在 8 分钟演出流程中稳定操作。

## 2. 推荐架构：独立落地式手动转运台

推荐先制作低复杂度、无动力的模块化转运台：

- **A. 独立底座**：四点支撑或宽底框架，带防滑脚垫；不与车辆或购物车刚性连接。
- **B. 购物车定位区**：地面止轮块/定位挡块，让购物车靠近转运台并保持稳定；不把装置固定到购物车上。
- **C. 可调接料平台**：平台高度可调，以适配实际购物车篮筐/置物层高度；平台表面铺软垫或可更换低摩擦衬面。
- **D. 可调侧导轨**：两侧导向，防止物品偏出；导轨间距根据三件物品实测值调整。
- **E. 手动推板/转运托盘**：带软质接触面的推板或可抽拉托盘，队员逐件推动/承托物品进入结账区域。
- **F. 末端止挡与接收区**：限制物品过冲；接收区域边界清楚，便于裁判确认三件物品均已进入结账区。

初始动作序列：
1. 将独立转运台放置在结账区允许的位置，确认底座稳定。
2. 将购物车停稳在定位区，使用轮挡/制动防止意外移动。
3. 调整平台高度、导轨间距和托盘位置。
4. 每次转运一件物品；易碎或不规则物品优先使用承托托盘，不用推板直接顶压。
5. 目视确认物品完全进入结账区域后，再转运下一件。
6. 清点三件物品，移除/复位活动部件，按题面时序继续购物车释放与返区流程。

## 3. 备选机构与选择门槛

| 方案 | 适用情况 | 优点 | 风险/限制 |
|---|---|---|---|
| 手动推板 + 导轨 | 物品底面平整、可安全滑移 | 结构简单、动作直观、复位快 | 不适合易碎、滚动或易倾倒物品 |
| 抽拉式承托托盘 | 物品易碎、不规则或不宜推压 | 承托稳定、接触压力较小 | 需要足够托盘行程和操作空间 |
| 手动翻转/倾斜托盘 | 三件物品均可承受缓慢倾斜且不会滚落 | 一次动作可完成转移 | 重心、夹点、冲击和物品滑落风险较高；未测前不推荐 |

**当前推荐：先做“可调接料平台 + 导轨 + 抽拉式承托托盘”，推板作为可替换附件。** 不建议第一版采用弹射、弹簧释放、快速翻斗或电动执行器。

## 5. 结构与安全要求

- 底座不得翘脚；推拉托盘时不得整体滑移或倾覆。
- 购物车必须先制动/止轮，再开始卸载；卸载动作不得把购物车推离定位区。
- 所有接触物品的边缘倒圆并加软质护面；导轨间隙不得形成夹手剪切点。
- 托盘必须有机械止挡，不能从导轨中意外抽脱。
- 物品在整个转运过程中应有连续承托；不允许从高处自由跌落。
- 平台调节机构必须有锁止，不能仅靠摩擦力保持高度。
- 先做无动力、空载台架检查，再做单件轻载测试，最后做三件连续测试。
- 车辆保持无人乘坐状态；本装置测试不构成乘坐式车辆安全验收。
