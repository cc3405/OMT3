# 2026–2027 Problem 1 统一制作与采购总表（主控文件）

> 版本：MASTER-PLAN-0.1｜日期：2026-10-31

> 本文件统一购物车、三件道具、独立卸载装置、车辆电子/机械系统、采购优先级和验收门槛。后续采购和制作以本文件为唯一主清单；旧 BOM 中与本文件冲突的购物车/连接件条目暂停使用。

## 0. 本版目标与不可承诺事项

目标是做出一个结构简单、规则边界清楚、可反复排练的 Division II 原型：车辆按规则执行购物任务，购物车承载三件物品，队员使用**与车辆完全分离的队伍自制人力卸载装置**把物品转入结账区域。

“能通过”应理解为按规则设计并逐项取得测试证据，不能由文档或采购清单保证裁判结果。当前尚无整车 CAD、承载结构计算、完整软件、实物测试和完整成本闭合，因此：
- 不进行真人乘坐或动力载人测试。
- 不采购/加工座椅、承载车架、转向、制动、牵引承载件等安全关键件，直到工程审查完成。
- 不把电机、舵机、BMS、驱动板的商品宣传峰值当作设计额定值。
- 任何尺寸/质量的“目标值”均须用到货实物测量替代。

## 2. 采购分级

- **A｜可先采购（低风险、规格较清楚）**：道具、标签、独立卸载装置的通用小件/样板材料、低压开发板（确认板型后）。
- **B｜测量后采购**：卸载装置正式板材/滑轨长度、购物车牵引转接件、舵机支架/夹爪、型材切割件、轮子和电机支架。
- **C｜工程计算后采购**：电机、电机驱动、电池/BMS/充电器、保险丝、接触器、主线径、舵机和大电流 DC-DC。
- **HOLD｜暂不采购**：乘坐式承载车架、座椅/乘员支撑、转向、制动、牵引承载结构、任何按参考图片直接估尺寸的定制件。

## 6. 独立卸载装置验收（必须单独记录）

- U-01 独立性：无任何车辆机械、电气、控制连接。
- U-02 稳定性：最大实测道具负载下底座不翘脚、不滑移、不倾覆。
- U-03 单件转运：每件物品单独重复转运，无掉落、损坏、卡滞。
- U-04 三件连续卸载：建议至少连续10轮记录，目标至少9轮完整成功；保留失败原因和时间。
- U-05 购物车定位：卸载时购物车不会意外移动。
- U-06 操作安全：无明显夹手、割伤、倾倒、过冲风险。
- U-07 演出时序：能在规则时序和演出时长内完成，不妨碍其他任务。

测试次数/阈值是工程验收目标，不替代官方规则。

## 7. 当前禁止事项与安全底线

1. 禁止真人乘坐、载人动力测试和把“40kg额定乘员载荷”等需求文字当作已验证承载能力。
2. 结构、座椅、转向、制动、牵引承载件必须完成CAD、强度/稳定性分析和独立审查后才能制造。
3. 电池只用合规成品电池组和匹配充电器；不自行拼装裸电芯。
4. 急停必须硬件切断电机驱动能量；MCU复位/断线时驱动默认禁用。
5. ESP32-S3 GPIO为3.3V；HC-SR04 Echo、编码器和驱动器控制脚逐路核实，不得把未经适配的5V信号直连GPIO。
6. 所有载荷、速度、转矩、电流和温升必须测量记录；卖家宣传参数不能代替测试。
