# OMT3 OMER 购物服务原型 — 模块化拼装说明书 v0.1

> 版本日期：2026-10-31  
> 适用：2026–2027 Odyssey of the Mind Problem 1，团队 Division II 设计基线。  
> 文件性质：**采购候选与低风险模块的详细装配手册**，不是已完成整车工程图。  
> 重要：乘坐车辆的承载结构、转向、制动和乘员安全尚未通过专业审查；本说明书不授权载人或动力测试。

## 0. 开始前先看：本版可以做什么、不能做什么

### 可以按步骤进行
1. 购买并验收 Sakugi 80L 折叠 wagon（作为被牵引购物车，不是乘坐车辆）。
2. 准备 PET 瓶、泡沫球、请求缺货盒与替代盒。
3. 按实物测量结果制作独立、落地、手动的卸载台。
4. 进行无动力、空载、低风险的尺寸和装配检查。
5. 制作电子模块台架；电机输出断开，先检查逻辑和电平。

### 目前禁止作为“照图施工”的内容
- 乘坐式车辆底盘、座椅/乘员支撑、立柱、车轮轴、转向、制动、牵引座和任何承载件；
- 未知堵转电流的电机/驱动/电池配线；
- 任何人坐上车辆或 wagon；
- 未经核验就给 ESP32-S3 GPIO 接入 5V 信号；
- 以车载机械臂、舵机翻斗代替 Division II 独立卸载台。

原因：现有仓库没有可制造总装 CAD、孔位图、材料强度计算、制动测试或实物尺寸。缺这些资料时写出具体承载结构孔距/螺栓尺寸会是猜测，不是严谨说明书。

## 2. 组装总顺序（像乐高一样分包）

建议将零件分成 5 个编号盒：A 购物车、B 道具、C 独立卸载台、D 车辆机械结构、E 电气/软件。每个螺丝袋贴编号，未通过上一关卡不要进入下一包。

### 第 A 包：打开并验收 Sakugi 80L 购物车

**A-1 开箱**
1. 把纸箱放在平整地面。
2. 拍摄未开箱外包装、型号标签和订单 SKU。
3. 取出 wagon、布篮、说明书和所有附件；将小配件放入标记袋 A-S。
4. 对照说明书清点；缺件或变形先联系卖家，不要自行钻孔补救。

**A-2 展开车架**
1. 将车架放在地面，确认四个轮子没有被包装物卡住。
2. 按随车说明书释放折叠锁扣/拉开中心折叠结构；不同批次锁扣结构以实物说明书为准。
3. 缓慢向外展开四边框架，直到框架到达完全展开位置。
4. 检查四角铰接处是否都到位；不要用锤子强敲。
5. 检查车架是否能自行保持展开；若锁扣不闭合，停止使用并联系卖家。

**A-3 安装布篮**
1. 将布篮正面朝上铺开，确认没有破洞、脱线和缝线开裂。
2. 对齐布篮四角与金属框架四角。
3. 按随车说明将布篮挂带/魔术贴依次固定在金属框架上。
4. 先固定四角，再固定长边中点；逐个压紧粘扣。
5. 把布篮底部贴合框架底部，避免布料卷入车轮。
6. 用手沿篮口轻拉一圈，确认没有漏扣。

**A-4 轮子与把手检查**
1. 逐个转动四个脚轮，确认 360° 转向无卡点。
2. 推动把手至正常使用位置，确认伸缩锁止可靠。
3. 缓慢向前、向后推车，观察车轮是否偏摆、异响或松脱。
4. 测量展开最大长、宽、高；尤其记录最宽外廓和篮底有效尺寸。
5. 称量空车质量并拍照，数据写入项目测量表。

**A-5 安装可拆硬底板（必须先量尺寸）**
1. 用卷尺测量布篮内部底面长宽；在四角和中心各测一次，取最小有效尺寸。
2. 在纸板上画出底板模板，四周比实测最小内尺寸各缩小约 5–10mm，确保可放入、不撑开布篮。
3. 将模板放入篮底，确认不顶压车架铰链、不盖住锁扣。
4. 按模板裁切 6–9mm 胶合板或轻质板；所有边角打磨圆滑。
5. 在底板下表面粘贴薄防滑垫，避免板材磨破布篮。
6. 放入底板后用手压四角，检查是否摇晃、翘起或接触轮架。
7. 不把底板钻穿固定到 wagon 车架；先保持可拆卸。若需要固定，必须重新检查折叠功能和受力路径。
8. 不得将牵引力施加在布篮、布带或底板上；未来牵引点只能连接金属承载框架并另做工程校核。

**A 包验收**：展开/折叠顺畅；四轮可转；布篮固定完整；底板不翘、不磨布、不干涉折叠。未完成实测前不得安装牵引附件。

### 第 B 包：准备三件实际购买物

**B-1 星际补给瓶**
1. 取一个空 500mL PET 瓶。
2. 清洗并完全晾干；确认瓶体没有裂纹或尖锐毛边。
3. 瓶内保持空，不装液体或散装物。
4. 拧紧瓶盖。
5. 贴上团队原创标签，标签不得遮住瓶身主要抓取区域。
6. 测量瓶身最大直径、总高度、瓶盖直径并称重。
7. 在底部贴编号 B1；记录照片和实测值。

**B-2 能量球**
1. 从 3in 泡沫球包装中取 1 只作为正式比赛物品。
2. 检查球体没有裂缝、掉屑或明显压扁。
3. 使用明确适用于泡沫的颜料/胶水，先在备用球上试涂。
4. 完全干燥后称重并测量最大直径。
5. 不粘硬质尖头、钉子或金属装饰。
6. 标记 B2；剩余球作为训练备件，不要全部用于正式物品。

**B-3 缺货与替代盒**
1. 把蓝色小盒列为购物清单请求物品，目标尺寸约 120×80×50mm；当前没有已核实的购买链接。
2. 训练/演出时用空货位卡明确标注“蓝色盒缺货”。
3. 采购红色同类带盖盒作为替代品，实际长宽高/容量尽量接近蓝色盒。
4. 让购物助理明确说出并做出批准动作：“蓝色小盒缺货，红色同类盒可以替代吗？”“批准。”
5. 最终购买/卸载的三件物品是 PET 瓶、泡沫球、红色盒；蓝色缺货卡不是第四件物品。
6. 测量红色盒外廓和质量，标记 B3。

**B 包验收**：三件物品有形、可见、易区分；瓶子无液体；泡沫球不掉屑；盒子有盖；助理批准流程清楚可见。

### 第 C 包：独立手动卸载台（Division II 必做模块）

> 目标：队伍制作、独立落地、与车辆完全分离；由队员直接人力操作。第一版采用“底板 + 可调侧导轨 + 抽拉承托托盘 + 机械止挡”，不使用电机、舵机或车辆供电。

**C-0 先做测量卡，不测量不切板**
1. 量三件物品的最大长、宽、高和质量。
2. 量 wagon 篮底高度、篮口高度、篮口有效宽度、底板高度。
3. 在地面模拟 wagon 停靠位置和结账区边界。
4. 测量物品从篮内取出到结账区所需的最短转移距离。
5. 记录操作者站位、手臂可达范围和抽拉方向。
6. 依据这些数据画 1:1 纸板布局图；先用纸箱/废板模拟，不先切正式板材。

**C-1 组装底座**
1. 将底板放在平整工作台上，标记四角和中心线。
2. 在底板下表面四角附近定位 4 个防滑脚垫。
3. 先用胶粘/螺栓临时固定脚垫，确认四点同时接触地面。
4. 把底板放地上轻推，检查是否滑动或翘脚。
5. 若底板轻推就移动，扩大底座或换高摩擦脚垫；不得靠操作者用脚踩住来补偿不稳定。

**C-2 安装左右导轨**
1. 将托盘放在底板中心线上。
2. 把左右导轨平行放在托盘两侧。
3. 先用夹具临时定位，测量导轨前后端间距；两端差值应尽量小，避免托盘卡斜。
4. 按实测最大物品宽度和托盘宽度设置净间隙；留出滑动间隙，不得夹住物品。
5. 标记孔位后再钻孔；孔边倒角、去毛刺。
6. 用螺栓、垫片和锁紧螺母固定导轨；所有螺栓头不得伸入托盘滑动通道。
7. 手推托盘全行程 10 次，检查卡滞和左右晃动。

**C-3 安装抽拉托盘**
1. 将空托盘放在导轨起始端。
2. 按导轨实际结构把托盘与两侧滑块连接；若用抽屉滑轨，左右滑轨必须同高度、同方向。
3. 在托盘接触面铺薄软垫，避免硬物撞击瓶身或盒角。
4. 在托盘两侧安装低矮防脱边；高度以不遮挡装载、又能阻止物品侧滑为准。
5. 在托盘末端设置机械止挡，确保托盘不会被完全抽脱。
6. 安装防滑手柄；手柄螺栓必须有锁紧措施。
7. 空载往复 20 次；若有卡滞，先校正平行度，不得强拉。

**C-4 安装 wagon 定位区**
1. 把卸载台放在结账区允许的区域外缘，确认不会遮挡表演通道。
2. 在底板上标出 wagon 轮子停靠位置。
3. 制作两个可拆轮挡，分别限制 wagon 前后移动。
4. 轮挡只与地面/卸载台接触，不永久连接 wagon。
5. wagon 停入后，轻推车架检查轮挡能否阻止意外滚动。
6. 若 wagon 仍移动，先检查地面坡度和轮挡形状，不要用绳子把 wagon 绑到卸载台或车辆上。

**C-5 三件物品转运动作**
1. wagon 完全停稳并用轮挡固定后，操作者站在规定操作侧。
2. 一次只取一件物品，先将其完全承托在托盘上。
3. PET 瓶以瓶身中段托持，不夹瓶盖；泡沫球放入浅托位，不用尖齿夹紧；盒子托住底面。
4. 缓慢抽拉托盘，使物品完整进入结账区域。
5. 物品完全进入结账区后停止，确认没有越过边界或滚出。
6. 将托盘复位，再转运下一件。
7. 三件全部进入结账区后，由购物助理清点订单并完成结账核验。
8. 不允许物品从高处自由跌落，不允许用弹簧弹射、快速翻板或推板撞击物品。

**C-6 安全与验收**
1. 用手沿所有边缘摸一圈，确认无毛刺、尖角和割手点。
2. 在托盘最大行程处检查剪切/夹手缝隙；必要时加软护条。
3. 轻推底座检查翘脚、滑移和倾覆。
4. 对每件物品单独转运 5 次。
5. 连续三件转运 10 轮，逐轮记录时间、卡滞、掉落、越界。
6. 目标工程验收：至少 9/10 轮三件都完整进入结账区，且无明显安全风险；这不是规则官方评分保证。
7. 拍摄从 wagon 定位、逐件转运到三件结账区确认的连续视频。

**C 包验收**：独立落地、不连接车辆；手动操作；三件均进入结账区；无滑移/倾覆/夹伤风险。未测前状态保持“未测”。

### 第 D 包：乘坐式车辆（当前只允许做图纸和非承载模块准备）

**D-0 设计冻结资料**
1. 完成 1:1 总装 CAD，包含底盘、轮距、轴距、乘员支撑、立柱、把手、电池、驱动器、牵引座、线束、护罩和购物车扫掠包络。
2. 标出完整外廓和 28×78in 门口通过姿态。
3. 完成载荷路径、材料、连接方式、静载、倾覆、转向、制动和急停设计审查。
4. 取得电机、轮毂、轴、驱动器和电池数据表，计算启动/堵转电流。
5. 由具备相应能力的成人/专业人员审查并书面放行后，才进入承载结构制造。
6. 本说明书不提供承载结构孔位、焊接参数或载人装配步骤，因为当前没有足够工程输入。

**D-1 低风险电子安装准备**
1. 在独立电子安装板上规划 ESP32-S3、驱动器、保险丝、DC-DC 和接线端子位置。
2. 保留 USB 插拔空间、散热空间和保险丝可维护空间。
3. 信号线与电机大电流线分开走线。
4. 所有电源端子加防触碰绝缘罩。
5. 急停按钮放在操作者可直接触及的位置，并由硬件切断电机驱动电源。
6. 未确认驱动器逻辑阈值和电机电流前，不连接电机电源。

### 第 E 包：电子与固件台架

**E-1 ESP32-S3 板检查**
1. 确认具体板型为 N16R8，核对 Flash/PSRAM、USB 下载方式和引脚图。
2. 只接 USB 供电，检查串口和下载是否正常。
3. 记录板上 LED、USB-UART 和可用 GPIO；避开被 PSRAM/USB/启动配置占用的引脚。
4. 先不要接电机驱动器或舵机。

**E-2 传感器电平检查**
1. HC-SR04 使用 5V 供电时，Echo 线路必须经过分压/电平转换。
2. 先用万用表测量 Echo 高电平。
3. 确认 ESP32-S3 GPIO 输入端最高不超过 3.3V。
4. 编码器 A/B 相也逐路测量；若输出超过 3.3V，必须适配。
5. 不确定电平时保持断开。

**E-3 驱动与急停检查**
1. 核对 IBT-2/BTS7960 的具体版本和原理图。
2. 核实 R_EN/L_EN 逻辑阈值与 3.3V GPIO 兼容性；不兼容时加适当电平转换。
3. 使能脚加外部下拉，保证 MCU 复位时禁用。
4. 硬件急停必须能物理断开电机驱动能量。
5. 先只给逻辑板供电，再用限流电源做空载/车轮悬空检查；没有安全审查不得装载或载人。

**E-4 固件状态**
当前 `esp32_s3.ino` 只支持串口 help/status/arm/disarm/fwd/rev/left/right/stop 的短脉冲点动。没有完整导航、机械臂、购物车释放或任务状态机。先固定 Arduino-ESP32 版本并编译；保存构建日志。不要把代码存在当作运行通过。
