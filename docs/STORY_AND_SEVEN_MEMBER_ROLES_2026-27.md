# OMER 太空补给服务：完整故事剧本与七人分工（2026–2027）

> 版本：STORY-TEAM-0.1｜排练目标约7分30秒至8分钟｜固定七名队员
> 道具基线：空500mL PET瓶、76mm软泡沫球、红色带盖盒；蓝色盒仅作缺货请求物品/货位标识。
> 本稿是故事与排练方案，不是规则裁定，也不证明设备已通过测试。

## 一、故事：《OMER太空补给站：最后一份订单》

不久的未来，地球与月球之间开通了定期补给航线。月球基地“宁静港”即将进行重要的科学观测，样本整理仓却突然发生故障。基地向OMER太空购物服务中心发来紧急订单：一个空的500毫升样本瓶、一只76毫米软质训练球，以及一只蓝色密封盒。补给窗口只剩八分钟。

OMER团队抵达货架区后发现蓝色密封盒售罄。团队不能假装商品已经买到，也不能擅自替客户更换。队员找到一只红色同类带盖盒，必须由购物助理检查并明确批准。之后，团队还要使用与车辆完全分离的独立手动卸货装置，把三件最终商品逐件送到结账区，完成核验，并按任务要求把购物车送回指定区域。

故事主题：**真正可靠的服务，不只是速度，更是诚实沟通、客户确认、团队协作和安全完成任务。**

## 三、完整七幕剧本

### 第一幕：来自月球的紧急订单（0:00–0:45）

**舞台：** 7号在侧前方举起“宁静港月球基地”任务牌；2号拿订单板；1号在车辆起始位置待命；3、4号在货架区；5号在结账区；6号在独立卸货器旁。

**7号：**“这里是OMER太空补给服务中心！月球基地宁静港发来紧急订单，样本整理工作马上开始，补给窗口只剩最后几分钟。OMER小队，请接收任务！”

**2号：**“订单确认：第一件，空的500毫升样本瓶；第二件，直径约76毫米的软质训练球；第三件，蓝色密封盒。三件都要送到结账区，不能漏项。”

**7号：**“请注意，计时开始后，购物清单必须在车辆越过起始线之前交给车辆操作员。”

**动作：** 2号把清单交给1号。

**1号：**“订单收到。我先核对三项，再开始执行。OMER一号车，准备出发。”

**动作提示：** 清楚展示清单交接；按正式题面规定的时序开始后续动作。

### 第二幕：补给车出发，货架区开始搜寻（0:45–1:45）

**7号：**“OMER一号车已收到订单，正在前往补给货架区。货架管理员，请报告库存！”

**3号：**“货架系统上线！样本瓶库存正常，训练球库存正常……等等，蓝色密封盒的货位显示空缺！”

**4号：**“我确认一下。蓝色盒的货位确实空了，货架上没有可交付的蓝色盒。”

**3号：**“库存记录也显示售罄。我不能把没有的商品算作已采购，必须向购物助理报告缺货。”

**4号：**“我先把已有的两件商品找齐：样本瓶一件，软质训练球一只。第三件等助理确认后再处理。”

**动作提示：** 4号依次展示PET瓶和软球，交给指定承载位置。蓝色盒只展示为缺货货位牌，不混入最终交付物。

### 第三幕：突发缺货，团队共同作出决定（1:45–2:50）

**动作：** 3号走向2号，举起蓝色缺货标识。

**3号：**“购物助理报告：蓝色密封盒缺货。我们找到一只红色带盖盒，尺寸和用途类别接近，但颜色不同。是否允许替代，必须由你确认。”

**2号：**“先不要放进订单。我要确认它是不是同类物品，能否完成月球基地的收纳任务。”

**动作：** 4号拿起红色带盖盒，展示盒盖和内部空间。

**4号：**“这只红色盒有盖，内部空间与请求物品接近，可以用于收纳样本配件。它不是蓝色盒，所以我不会把它说成原商品。”

**2号：**“我代表客户批准这次替代：蓝色密封盒缺货，改用红色同类带盖盒。请在订单记录里注明‘经购物助理批准的替代品’。”

**3号：**“收到。我更新库存记录：蓝色盒缺货，红色盒作为替代品出库。”

**1号：**“替代信息已确认。最终订单是样本瓶、训练球、红色替代盒，对吗？”

**2号：**“正确。三件物品，一件替代，记录必须清楚。”

**7号：**“危机解决！OMER团队没有隐瞒缺货，也没有擅自更换商品。客户确认之后，订单才继续执行。”

**动作提示：** 红盒成为最终第三件商品；蓝色标识留在货架区作为缺货证据。

### 第四幕：前往结账，独立卸货装置登场（2:50–4:30）

**动作：** 1号把车辆/购物车带到结账操作位置并按规则停稳。5号准备核验。6号站在独立卸货器旁，展示装置与车辆之间没有连接。

**5号：**“结账台已准备。请提交三件商品和替代说明。”

**2号：**“最终订单：空样本瓶一件、软质训练球一只、红色带盖替代盒一只。蓝色盒缺货，替代品已由我批准。”

**6号：**“我负责独立卸货。这个托盘装置由队伍制作，独立落地、手动操作，不连接车辆，也不使用车辆的电源或控制系统。我会逐件承托、平稳转运。”

**7号：**“请注意，独立卸货装置不是车辆上的机械臂，也不是购物车的一部分，它必须保持独立。”

**动作提示：** 6号检查底座、防滑脚垫、导轨和止挡；按设计摆放装置。购物车独立止轮并确认稳定。6号逐件把三件商品从交接位置移到托盘，再手动送到结账区，每次只移动一件。

**6号：**“第一件，样本瓶，已承托。第二件，训练球，已承托。第三件，红色替代盒，已承托。三件均已送达结账区，托盘复位。”

### 第五幕：结账核验与订单闭环（4:30–5:30）

**动作：** 5号逐件检查商品，2号在旁确认替代说明。

**5号：**“结账核验开始。第一件：空样本瓶，数量一，确认。第二件：软质训练球，数量一，确认。第三件：红色带盖盒，数量一，替代品标记齐全。”

**5号：**“原请求蓝色盒没有被冒充成已购商品；缺货原因和替代批准记录完整。三件最终交付物均在结账区。”

**2号：**“订单内容与客户确认一致。谢谢团队没有为了赶时间跳过确认步骤。”

**3号：**“库存记录同步完成：蓝色盒缺货，红色盒替代出库。”

**7号：**“结账成功！但任务还没有结束。OMER一号车还要按任务要求完成购物车返区和最终停放。”

### 第六幕：购物车返区与最终停放（5:30–7:15）

**动作：** 1号回到车辆操作位置，其他角色离开运动路径。车辆与购物车按正式规则完成规定路线、越线、停车和释放时序。

**1号：**“商品交付完成。我将按任务规定完成购物车返区。所有人员离开车辆和购物车运动路径。”

**7号：**“返区阶段开始。请观察车辆、购物车和起始线之间的位置关系。只有完成规定越线、停车和释放时序，购物车最终停入目标区域，任务才算闭环。”

**动作提示：** 车辆只按已验证的安全流程操作。实际比赛若涉及乘坐式车辆，必须先完成结构、制动、稳定性和安全放行；未放行前只做静态走位或无乘员演练。购物车最终静止位置必须清楚可见，不能靠台词代替实际位置。

**1号：**“车辆已按流程停稳。购物车释放动作完成，等待最终位置确认。”

**7号：**“购物车已到达目标停放区——以现场实际位置为准。返区确认完成。”

### 第七幕：月球回讯与团队收尾（7:15–8:00）

**动作：** 2号拿起通讯器/任务牌，7号播放月球基地回讯，全体面向观众。

**2号：**“宁静港基地收到补给。样本瓶、训练球和替代盒都已核对。谢谢OMER团队！”

**3号：**“我们证明了，诚实报告缺货，比假装一切正常更重要。”

**4号：**“认真寻找、逐件交接，才能让订单不丢失。”

**5号：**“清楚核对，让每件商品都有记录。”

**6号：**“独立卸货，安全、稳定、一步一步完成。”

**1号：**“车辆负责运输，但完成任务靠的是整个团队。”

**7号：**“OMER太空补给服务——不只是把东西送到，更要把承诺安全、准确地送到！”

**全体：**“订单完成，宁静港，补给成功！”

## 四、七名队员详细职责

### 1号：任务驾驶员 / 车辆操作负责人
- **赛前：** 熟悉官方路线、起始线、购物车连接/释放顺序；参与操作界面和状态提示设计；检查车辆操纵件和操作区域。
- **比赛中：** 按规定在越线前接收购物清单；操作车辆和购物车完成规定移动；按验证流程停车、释放和返区。
- **台词：**“订单收到”“我先核对再出发”“所有人员离开运动路径”“车辆停稳，等待确认”。
- **交接：** 从2号接收订单；向5号/6号确认购物车已停稳可交接；向7号报告阶段完成。
- **权限边界：** 不批准替代品、不擅改牵引结构；车辆未安全放行前不得真人乘坐或动力载人测试。
- **赛后/备份：** 协助记录购物车流程、故障和返区复盘。

### 2号：购物服务助理 / 客户授权负责人
- **赛前：** 编制订单卡、缺货替代确认卡和最终订单清单；练习商品类别与用途说明。
- **比赛中：** 在规定时间将清单交给1号；确认3号的缺货报告；检查4号提出的红盒；明确批准或拒绝；向5号提交最终订单。
- **台词：**“先不要放进订单”“我代表客户批准这次替代”“最终订单是三件……”。
- **交接：** 向1号交订单；接收3号缺货报告和4号替代说明；向5号交最终订单。
- **权限边界：** 不伪造库存，不把未经批准的替代品计入订单。
- **赛后/备份：** 协助7号核对故事节奏和台词。

### 3号：货架管理员 / 库存记录负责人
- **赛前：** 制作货架标签、蓝色缺货货位牌、红色替代品标签和库存状态卡。
- **比赛中：** 报告样本瓶、软球有货；明确报告蓝色盒缺货；向2号提交事实；获得批准后登记红色替代盒出库。
- **台词：**“货位确实空了”“我不能把没有的商品算作已采购”“蓝色盒缺货，红色盒替代出库”。
- **交接：** 向2号报告缺货；与4号确认替代实物；向5号说明库存记录。
- **权限边界：** 不自行决定替代，不把蓝色缺货标识当作第四件商品。
- **赛后/备份：** 清点道具、检查标签和库存道具完整性。

### 4号：商品搜寻员 / 商品交接负责人
- **赛前：** 测量三件道具尺寸和质量；制作标签；练习逐件展示和交接；确认红盒与请求盒的类别/容量关系。
- **比赛中：** 找到并展示PET瓶和软球；确认蓝盒货位为空；向2号展示红盒用途和结构；把最终三件商品按流程交到承载/交接位置。
- **台词：**“我确认货位为空”“这只红色盒有盖，容量接近”“我不会把它说成原商品”。
- **交接：** 向3号反馈货位情况；向2号说明替代品；向6号交接三件实物。
- **权限边界：** 不替客户批准替代，不在结账后私自换货。
- **赛后/备份：** 管理备用道具、掉落复位和尺寸记录。

### 5号：结账核验员 / 订单闭环负责人
- **赛前：** 制作最终订单核验表，写清三件商品识别特征、数量和替代备注。
- **比赛中：** 在6号卸货完成后逐件检查；确认PET瓶、软球、红盒均到位；确认蓝盒缺货与红盒替代记录；宣布结账结果。
- **台词：**“第一件确认、第二件确认、第三件替代标记齐全”“三件最终交付物均在结账区”。
- **交接：** 接收2号最终订单和6号卸货完成信号；向7号报告结账完成。
- **权限边界：** 不把口头声明当作物品到位，必须逐件看到实物。
- **赛后/备份：** 核对成本表、道具清单和比赛携带清单。

### 6号：独立卸货员 / 卸货装置负责人
- **赛前：** 负责独立卸货器样机装配；检查导轨、止挡、防滑垫；完成U-01至U-07测试记录；确认装置与车辆无机械、电气或控制连接。
- **比赛中：** 独立摆放并确认稳定；按规则定位购物车；逐件承托、手动转运三件物品；确认托盘复位、物品全部进入结账区。
- **台词：**“装置独立落地、不连接车辆”“第一件已承托……三件均已送达”。
- **交接：** 从4号接收商品；向5号报告卸货完成；必要时向1号确认购物车稳定。
- **权限边界：** 不把车载夹爪称为独立卸货装置；购物车未稳定时不强行操作。
- **赛后/备份：** 管理维修工具、备用紧固件和装置检查。

### 7号：任务通讯官 / 舞台调度与计时负责人
- **赛前：** 统筹剧本、台词、音效、站位和转场；准备计时提示；确认七人都有台词和动作；组织连续排练并记录超时点。
- **比赛中：** 讲述任务背景；用简短提示连接各幕；提示清单交接、缺货确认、卸货和返区节点；不干扰裁判观察。
- **台词：** 交代任务、播报阶段、强调关键动作、宣布月球回讯。
- **交接：** 接收1号/5号阶段完成口头确认；向全队发出转场提示。
- **权限边界：** 不替1号操作车辆、不替2号批准替代、不替5号核验实物，也不代替现场实际位置宣布通过。
- **赛后/备份：** 负责演练录像、计时、失误清单和复盘。

| 5:30–7:15 | 购物车返区、停车、释放 | 1、7 | 按题面顺序完成，实际位置可见 |
| 7:15–8:00 | 月球回讯、团队收尾 | 全体 | 七人各有台词/动作，收尾简洁 |

以上是内部排练预算，不是官方分项时限。若动作耗时增加，优先压缩旁白、重复台词和转场，不得删掉清单交接、替代批准、独立卸货、逐件核验或购物车返区等关键动作。

## 七、每轮排练检查清单

- [ ] 1号准确复述清单并完成规定时序交接。
- [ ] 2号明确说出替代批准，不由别人代批。
- [ ] 3号展示蓝盒缺货事实，蓝色标识未混入最终商品。
- [ ] 4号展示两件有货商品和红色替代盒，交接数量正确。
- [ ] 5号逐件看到三件实物后才宣布结账完成。
- [ ] 6号的卸货装置独立落地、无车辆连接，托盘动作平稳无掉落。
- [ ] 7号旁白简短，不遮挡关键动作；全队在8分钟内完成。

建议至少进行五轮完整计时排练。每轮记录总用时、各幕用时、错词、漏动作、掉落/卡滞、车辆/购物车位置问题和视频证据；失败轮次也保留，修正后重测。

## 八、角色替补与公平性

- 每个关键岗位至少指定一名熟悉流程的替补，但正式演出仍由七名队员共同完成。
- 替补训练不代表临场可随意交换职责；更换角色后要重新练习交接。
- 每人都应理解全流程，但规则关键动作由指定负责人执行。
- 可按队员年龄和能力调整动作难度、台词长度，但不得增加第八名演员。
- 技术动作须在教练/成人监督下按适用安全要求进行；车辆未完成安全审查前，不安排真人乘坐或动力载人演练。

## 九、导演提示

1. 用倒计时制造紧张感：7号每幕播报一次即可，避免不断打断动作。
2. 让缺货成为真正冲突：先展示蓝色货位空，再由4号提出红盒，最后由2号批准。
3. 让七人都推动剧情：驾驶员运输、助理授权、管理员报告库存、搜寻员找商品、核验员结账、卸货员转运、通讯官串联全场。
4. 把卸货器称为“月球基地样本安全转运台”可以增强故事感，但真实结构仍须独立落地、手动操作、与车辆无连接。
5. 用清楚动作代替长解释：让观众看到缺货、审批、逐件卸货、核验和购物车停放。
6. 结尾回扣主题：OMER的成功不只是速度，而是诚实、协作、准确和安全。

**最终提醒：** 官方评分、任务动作和场地时序以当季正式题面、澄清和Program Guide为准。任何技术/安全动作未实测前，都不得在剧本中宣称已经验证通过。
