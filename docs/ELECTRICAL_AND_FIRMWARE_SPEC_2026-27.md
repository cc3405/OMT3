# 电气与固件接口规范（2026–2027）

> 版本 0.1｜适用于 ESP32-S3 候选控制系统。  
> 当前仓库固件为串口点动骨架，不是完整任务控制器；本文是实现规范，不声称代码已实现或编译通过。

## 1. 电源域划分

```text
3S 成品电池组（电压范围以电池数据表为准）
        │
   主保险丝（靠近电池正极）
        │
  DC额定主接触器/开关
        │
        ├── 左电机驱动器 ── 左驱动电机
        ├── 右电机驱动器 ── 右驱动电机
        ├── 5V DC-DC ── ESP32-S3 + 传感器
        └── 独立舵机 DC-DC（若机械臂采用舵机）── 舵机电源轨

硬件急停：直接使主接触器释放/切断驱动能量；
MCU软件急停只能作为附加层，不能替代硬件急停。
逻辑地与驱动信号参考地按驱动器资料单点规划；
电机大电流回路不得经过开发板地线。
```

以上为功能框图，不是接线施工图。保险丝、接触器、线径、端子、DC-DC额定值必须根据准确SKU、电机堵转/启动电流、舵机峰值电流和线长计算。

## 2. 上电前强制检查

- [ ] 电池是带保护的合规成品电池组，充电器与化学体系/串数/接口匹配。
- [ ] 主保险丝靠近电池正极，额定值低于受保护导线允许电流，同时能承受正常启动电流。
- [ ] 急停直接控制直流额定接触器/安全断能回路；不能只把GPIO拉低。
- [ ] 急停按下后，驱动器电机输出能量实际被切断；控制器仍可保留低压状态指示。
- [ ] 逻辑5V、舵机电源和电机主电源分支明确；舵机峰值电流不从开发板5V脚取电。
- [ ] ESP32-S3 GPIO为3.3V逻辑域；任何5V Echo/编码器输出须经核实的分压/电平适配。
- [ ] 电机、驱动板和DC-DC的散热/通风与安装绝缘完成。
- [ ] 电池固定、防短路、防磨损、防反接和线束应力释放完成。
- [ ] 首次上电使用限流电源，电机输出断开或车轮悬空。

## 3. GPIO 分配原则

具体 GPIO 号必须在确认开发板 SKU 和完整原理图后冻结；此处不伪造引脚号。

| 信号组 | 数量 | 方向 | 约束 |
|---|---:|---|---|
| 左电机方向/PWM | 2–3 | 输出 | 依驱动板接口确定；复位默认禁用 |
| 右电机方向/PWM | 2–3 | 输出 | 与左侧同原则 |
| 编码器 A/B | 4 | 输入 | A/B双相读取才能判断方向；核实输出电平 |
| 超声波 TRIG/ECHO | 6 | 输出/输入 | 前/左前/右前3只，错峰触发；ECHO按电压适配，不得5V直连 |
| 限位开关 | 4 | 输入 | 使用硬件上拉/下拉；关键限位必须参与运动联锁 |
| 急停状态反馈 | 1 | 输入（可选） | 仅监测，不替代硬件断能回路 |
| 舵机PWM（ESP32-S3 LEDC） | 3 | 输出 | 默认直接输出肩/肘/夹爪三路PWM；PCA9685仅在台架验证LEDC资源/抖动不满足时选配 |
| 状态LED/蜂鸣器 | 2 | 输出 | 通过限流电阻/驱动管，不直接驱动未知负载 |

## 4. 软件状态机（目标实现）

```text
BOOT_SAFE
  └─ 自检通过且急停释放 → IDLE
IDLE
  ├─ 操作员明确使能 → READY
  └─ 故障/急停 → FAULT
READY
  ├─ 收到有效且限时命令 → MANUAL_MOVE
  ├─ 任务开始 → TASK_WAIT_LIST
  └─ 故障/命令超时/急停 → FAULT
TASK_WAIT_LIST
  └─ 收到清单确认 → TASK_TO_SHOP
TASK_TO_SHOP
  └─ 到达购物区/操作员确认 → TASK_PICK
TASK_PICK
  └─ 三件物品完成；缺货分支经购物助理确认 → TASK_TO_CHECKOUT
TASK_TO_CHECKOUT
  └─ 到达结账区 → TASK_UNLOAD
TASK_UNLOAD
  └─ 独立人力卸载器完成、三件物品可见 → TASK_RETURN
TASK_RETURN
  └─ 车辆/购物车越起始线并满足释放时序 → TASK_RELEASE
TASK_RELEASE
  └─ 车辆停稳、购物车释放并最终停入指定区域 → COMPLETE
任意状态
  └─ 急停/传感器故障/失联/看门狗超时 → FAULT（驱动禁用）
FAULT
  └─ 人工排查并复位 → BOOT_SAFE
```

状态机中的购物助理确认和独立卸载动作必须由真人完成；软件状态不能代替规则要求的实际动作。

## 5. 命令安全策略

- 上电默认电机禁用，PWM=0，方向输出进入已定义安全态。
- 串口/遥控命令必须包含有效范围、序号或校验字段、超时和最大动作时长。
- 通信超时必须让电机输出进入禁用态；不能只停止刷新显示。
- 急停触发后锁存 FAULT，不能自动恢复运动。
- 超声波读数无效、超范围或连续丢失时，采取保守停止/禁用策略。
- 限位开关应在硬件/软件中阻止危险方向继续运动，不得仅打印状态。
- 编码器方向判断须使用A/B相；仅A相计数不能可靠判断方向。
- 任务状态变化需记录时间戳、输入原因和故障码，便于复盘。

## 8. 自动避障控制补充（目标实现，尚未编码验证）

### 传感器与状态
- 3只超声波固定朝向：前、左前、右前。Trig/Echo逐只错峰触发；回波超时记为无效，不把无效值当作“无限远”。
- 传感器滤波采用最近3–5次有效读数中值；连续无效/跳变进入STOP_SENSOR_FAULT。
- 建议首轮台架阈值从“前方停止距离约250–350mm、侧向通行余量约200–250mm”开始调试；这些是测试起点，不是已验证安全距离，须根据车速、制动距离、车头外廓和场地障碍重测。
- 状态机：CRUISE → OBSTACLE_STOP → COMPARE_LEFT_RIGHT → TURN_LEFT/RIGHT → VERIFY_CLEAR → CRUISE；两侧都不安全或多次失败进入SAFE_STOP。
- 转向用左右轮编码器闭环；每次转弯后重新测距。设最大连续转向次数和总行驶时间限制，防止原地循环。
- 只做近场反应式避障，不包含地图构建、路径记忆、目标识别或动态人群预测。人员进入测试区域即人工急停。

## 9. 车载机械臂控制补充（目标实现，尚未编码验证）

- 首版为3个舵机：肩关节、肘关节、夹爪。车辆自身转向完成左右对准，避免额外底座旋转轴。
- 默认由ESP32-S3 LEDC直接产生三路舵机PWM；若后续选配PCA9685，其V+舵机电源必须来自独立DC-DC，PCA9685仅产生PWM，不给舵机供电。ESP32与舵机电源按控制器要求共信号参考地，舵机电流不经过开发板。
- 机械臂动作仅在底盘驱动禁用、车辆停稳时执行；底盘运动与机械臂运动互斥。
- 抓取状态：ARM_HOME → APPROACH_POSE → LOWER → CLOSE_GRIPPER → VERIFY_GRASP → LIFT → PLACE_IN_CARRIER → OPEN → ARM_HOME。
- 抓取确认失败最多进行一次受限重试；仍失败则保持停止并提示人工处理，不得反复夹压泡沫球或塑料盒。
- 肩/肘机械限位与软件限位双层保护；舵机失控、限位触发、欠压或控制器复位均进入ARM_FAULT。
- 不做视觉识别。物品须放在已测量的固定抓取区域；货架层高、前沿、篮筐网格和机械臂安装高度须先实测。



## 10. 机械臂降本电控基线（CAD v2）

- 默认ESP32-S3直接使用3路LEDC PWM驱动肩、肘、夹爪舵机，先进行PWM刷新率、抖动、复位默认状态台架测试。
- PCA9685不再是默认必购件；只有LEDC资源/时序验证失败时才加购，不能把PWM扩展板当舵机电源。
- 舵机使用独立DC-DC电源支路，按三个舵机同时动作和堵转峰值电流核算；逻辑地参考按具体驱动器资料处理。
- 机械臂与底盘运动互锁，车辆停稳且驱动禁用后才允许舵机动作。
