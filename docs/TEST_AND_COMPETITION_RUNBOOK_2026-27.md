# 综合测试计划与比赛执行手册（2026–2027）

> 版本 0.1｜用途：样机验证、排练、赛前检查。  
> 所有测试初始状态均为“未测”；只有填写结果、日期、视频/照片/日志链接后才能标记通过。

## 1. 测试总原则

1. 规则测试、机械测试、电气测试、软件测试分开记录；一个通过不能代替另一个。
2. 先无电、后低压；先静态、后动态；先空载、后受控负载。
3. 乘坐车辆在结构、制动、稳定性和安全审查完成前，不进行真人乘坐或动力载人测试。
4. 所有测试使用隔离区域、明确观察员和急停负责人；发生异常立即停止。
5. 失败测试保留复现条件和视频，不删除失败记录。

## 4. 购物车和道具验收

- 购物车：记录品牌、SKU、空车质量、长宽高、篮口/篮底尺寸、框架管径、脚轮直径、刹车/锁止方式。
- 道具：记录每件尺寸、质量、颜色、标签、盖子状态和可见性。
- 购物车牵引连接：先静态检查防脱、干涉和最小转弯包络；受力分析未通过前禁止拖行。
- 道具抓取：每件至少20次纸板/泡沫模型抓取或人工放置；记录成功率和掉落原因。

## 5. 电气和软件测试

- [ ] 电池/充电器型号、保护板、接头和运输要求核对。
- [ ] 主保险丝、接触器、急停、线径和端子额定值核算。
- [ ] ESP32-S3每个输入脚电压实测；5V Echo不得直连。
- [ ] 三只超声波错峰触发，近/远/斜面/软材料/窄杆读数误差已记录。
- [ ] 左右轮A/B编码器方向、距离和转角已标定；传感器无效或两侧受阻时进入停止态。
- [ ] 机械臂舵机使用独立稳压电源，启动/堵转峰值电流和温升已记录。
- [ ] 肩/肘机械限位有效；夹爪对瓶、球、盒均完成夹持确认和失败停机测试。
- [ ] 底盘运动与机械臂动作互斥，车辆停稳且驱动禁用后才允许抓取。
- [ ] 电机断开时先测PWM/方向逻辑；之后限流、车轮悬空测试。
- [ ] 急停按下时电机驱动能量硬件切断。
- [ ] 通信中断、控制器复位、看门狗超时、传感器无效值均进入安全态。
- [ ] 记录每次测试的电压、电流、温度、固件SHA、硬件SKU和环境。

## 6. 购物车返区专项测试

至少使用完整场地边界/等比例地面标记测试：
1. 开始时购物车至少一个接地点处于题面要求的购物车区域。
2. 车辆与购物车连接，车辆推进购物车穿过购物任务流程。
3. 完成购物/结账后按题面要求返回，购物车随车辆越过起始线垂直平面。
4. 车辆停稳并按时序释放购物车。
5. 购物车自行行进并最终静止，至少一个接地点位于购物车区域内。
6. 车辆保持在题面规定的起始线或其外侧位置。
7. 记录释放点、方向、地面摩擦、滚动距离、停车偏差和失败原因。

在该测试通过前，不可用“车辆已返航”替代购物车返区完成。

## 7. 8分钟比赛流程（排练版时间预算）

以下是团队内部排练时间分配建议，不是官方规定的分项时限。所有动作顺序仍以题面和澄清为准。

| 时间预算 | 动作 | 必须可见的证据 |
|---|---|---|
| 0:00–0:20 | 开始信号、清单交接 | 计时开始后、车辆越起始线前，操作员拿到清单 |
| 0:20–1:00 | 车辆/购物车进入任务流程 | 车辆原创推进，购物车跟随 |
| 1:00–3:20 | 购买三件物品 | 三件物品逐件可见；缺货物品明确出现 |
| 3:20–3:50 | 替代品确认 | 购物助理批准红色替代盒，订单状态清楚 |
| 3:50–4:50 | 前往结账/订单核对 | 助理检查最终订单 |
| 4:50–5:50 | 独立卸载装置转运三件物品 | 装置独立落地，三件全部进入结账区 |
| 5:50–7:20 | 车辆带购物车返回并完成越线/释放 | 车辆与购物车位置、释放时序清楚 |
| 7:20–8:00 | 购物车最终停区、完成信号、表演收尾 | 购物车最终接地点位于目标区域；车辆停在规定位置 |

如果现场题面定义的起始位置、区域几何或时序与本排练表不同，立即以官方原文和澄清修正。表演元素应融入任务动作，不得遮挡评分证据或拖延关键流程。
