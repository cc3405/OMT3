## 2. 独立卸载器概念尺寸（可调参数）

设计目标：一台独立落地的手动托盘台。它不是车辆附件；不与购物车固定连接。操作员先将物品放在托盘上，再拉动托盘把物品送到结账区。

| 部件 | 初始放样尺寸 | 说明 |
|---|---:|---|
| 底板 | 450×350×18mm | 仅用于1:1纸板/低风险原型；稳定性需测试 |
| 托盘有效面 | 300×240mm | 覆盖三件道具的摆放包络，边缘圆角 |
| 托盘侧挡边 | 高25–35mm | 防止小盒/球滚落；避免形成夹手边 |
| 导向轨道 | 2条，中心距约220mm | 长度/行程按购物车与结账区实测 |
| 托盘行程 | 初始250–300mm | 只作为样机范围，需场地实测 |
| 底座防滑脚 | 4个 | 位置靠近四角；底板不得翘脚 |
| 末端止挡 | 2个 | 限制托盘行程，另设防脱结构 |
| 手柄 | 1个 | 拉动时手指远离滑轨夹点 |
| 购物车止轮块 | 2个 | 独立放置，不与车或卸载台永久连接 |

**禁止冻结的尺寸：** 托盘高度、导轨长度、底座最终尺寸、安装孔位和止挡位置。必须先测购物车篮口高度、场地边界和操作员站位。

## 5. 卸载器部件加工说明

- 底板：先用纸板制作1:1模板，确认操作员站位和托盘行程，再选板材；所有外角R≥3mm或倒圆。
- 托盘：边缘设低挡边，接触面贴EVA；不得有尖锐金属边。
- 导轨：使用成对导向件，平行度由同一基准边测量；滑轨必须有机械防脱止挡。
- 手柄：安装在托盘前缘中心，拉动方向与导轨方向一致；握持区不得夹手。
- 止轮块：卸载前由队员放在购物车脚轮前后，不能把卸载器绑在购物车上。
- 调平：底板不得靠松散垫片临时支撑；若篮口高度变化，使用有机械锁止的调节件。

## 7. 车辆外廓控制

项目历史记录包含“宽度≤800mm”的内部设计约束。把它作为本项目设计上限时，必须测量所有状态下的最宽点：轮胎、轮罩、螺栓头、把手、支架和线束护套。建议 CAD 目标留至少40mm总余量；最终仍须以官方规则定义为准。此内部目标不能替代正式规则尺寸要求。

## 9. 车载机械臂尺寸放样（未冻结）
- 首版3执行器：肩关节、肘关节、夹爪；车辆转向承担左右对准，不加底座旋转轴。
- 夹爪全开净距目标≥90mm；采用圆角V形软垫夹指，覆盖瓶身、泡沫球和盒体的夹持接触。
- 先测三种道具的真实最大外廓、质量和重心，再决定臂长与舵机力矩。不要按示意图或网络套件尺寸直接开孔。
- 抓取区必须是已知几何：地面取物和货架取物分别记录目标点坐标；机械臂可达范围需覆盖两者并留避障余量。
- 肩/肘关节应有机械限位和防夹护罩；夹爪软垫不得形成尖角或剪切夹点。
- 车辆需在停车、驱动禁用后抓取；机械臂放入车载承托位后复位，再恢复导航。
